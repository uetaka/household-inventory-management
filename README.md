# 家の日用品 在庫管理（写真 → Claude → Google スプレッドシート）

「引き出し」単位でスマホから中身の写真を撮ると、Claude が品目と数量を認識し、
その場で確認・修正してから Google スプレッドシートの台帳に書き込む Google Apps Script（GAS）アプリです。

- 台帳はスプレッドシート。自前サーバーは不要
- 写真1回分は「その引き出しの現在の全量」として上書き（スナップショット方式）
- 認識結果は書き込む前に画面で修正できる
- 最低在庫を下回った品目は「買い物リスト」シートに自動で並ぶ
- 写真と認識結果の生データは履歴シートと Google ドライブに残る

## 費用

Claude API は claude.ai のサブスクとは別料金（従量課金）です。
既定のモデルは `claude-opus-5` で、写真1枚あたり数円、月100枚で400円前後が目安です。
`src/Config.js` の `MODEL` を `claude-sonnet-5` にすると3分の1程度になります。

## セットアップ

### A. clasp で一発セットアップ（推奨）

手元の PC に Node.js 18 以上が必要です。Google へのログインはブラウザで行います。

```bash
npm install
npm run login          # ブラウザが開くので Google アカウントで許可する
npm run bootstrap      # スプレッドシート作成 → コード投入 → Web アプリ公開
```

事前に https://script.google.com/home/usersettings で「Google Apps Script API」を ON にしておいてください。

`bootstrap` が終わると、スプレッドシート・Apps Script・Web アプリの URL が表示されます。
生成された `.clasp.json`（スクリプトID）と `.deployment-id`（Web アプリのデプロイID）はコミットしておくと、以後は次のコマンドだけで更新できます。

```bash
npm run deploy         # src/ を push して同じ URL のまま新バージョンに更新
npm run open:app       # Web アプリをブラウザで開く
npm run open:sheet     # スプレッドシートを開く
```

次に Web アプリの URL を開き、初回の権限承認を済ませると「初回セットアップ」画面が出ます。

1. 「シートを作成する」を押す（引き出し・品目マスタ・在庫・履歴・買い物リストの5シートとサンプルが入る）
2. Claude Console で発行した API キーを貼って「キーを保存して接続テスト」を押す（発行方法は次項）

この2つはアプリをデプロイした本人だけが実行できます。キーはスクリプトプロパティにだけ保存され、シートやコードには残りません。

### Claude API キーの作り方

https://platform.claude.com/settings/keys の「Create key」で作ります。選ぶ項目と推奨は次のとおりです。

| 項目 | 推奨 | 理由 |
|---|---|---|
| Linked account | 自分（Personal key） | このアプリはあなたのアカウントとして動く。Service account は共有・自動化用で家庭には不要 |
| Workspace | 専用ワークスペースを作って、それに限定する | 限定しないとリクエストごとにワークスペースIDが必要になる。ワークスペース単位で月の支出上限も設定できる |
| Expiration | カスタムで1年程度（または Never） | 期限は後から変更できない。1年なら期限7日前にメールが来るので、初回セットアップ画面から貼り直すだけで済む |

ワークスペースは https://platform.claude.com/settings/workspaces で作り、Spend limit に月の上限（例: 10ドル）を入れておくと暴走しても止まります。

キーを限定せずに作った場合（複数ワークスペース対応キー）は、スクリプトプロパティ `ANTHROPIC_WORKSPACE_ID` に `wrkspc_...` を設定してください。未設定だと接続テストで案内が出ます。

家族もスマホから使う場合は `src/appsscript.json` の `webapp.access` を `"ANYONE"`（Google アカウントでログインした人なら誰でも）に変えて `npm run deploy` し、URL を共有してください。

### B. GitHub Actions で自動反映（任意）

`main` に push するたびに Apps Script へ反映させたい場合は、次の2つを設定します。

1. `.clasp.json` と `.deployment-id` をコミット済みにする
2. 手元の `~/.clasprc.json` の中身をリポジトリの Secret `CLASPRC_JSON` に登録する

Secret が無い間はワークフローは何もしません。`~/.clasprc.json` には Google のリフレッシュトークンが入っているので、Secret 以外の場所には置かないでください。

### C. 手動で貼り付ける（clasp を使わない場合）

1. 新しいスプレッドシートを作り「拡張機能 > Apps Script」を開く
2. `src/` のファイルを同名で作って貼り付ける。`.js` は「スクリプト」、`Index.html` は「HTML」。`appsscript.json` は「プロジェクトの設定 > appsscript.json マニフェストを表示する」を ON にしてから貼る
3. 「デプロイ > 新しいデプロイ > ウェブアプリ」で公開し、URL を開いて上と同じ初回セットアップを行う

### シート構成

| シート | 役割 |
|---|---|
| 引き出し | 撮影単位。ID・名前・場所。自由に増やしてよい |
| 品目マスタ | 正規の品目名、単位、別名、最低在庫、定番商品、購入先。名前ゆれ防止と買い物リストの基準 |
| 在庫 | 引き出し × 品目の現在数量。アプリが上書きする |
| 履歴 | 撮影ごとの写真リンク、認識結果、確定結果、トークン数 |
| 買い物リスト | 最低在庫を下回った品目。確定のたびに更新 |

スプレッドシート側にも「在庫管理」メニューがあり、初期設定・接続テスト・買い物リスト更新を実行できます。

## 使い方

アプリ上部のタブで2つのモードを切り替えます。最初に「商品を登録する」でマスタを作ってから「在庫を数える」に進むのがおすすめです。

### 商品を登録する（品目マスタ作り）

1. いつも買っている商品を、パッケージの商品名・容量が読める距離で撮る。1枚に数個並べてもよい
2. 「Claude に読み取ってもらう」を押す
3. 種類名（品目名）・定番商品名・単位・カテゴリ・別名・最低在庫を確認して直す
4. 「品目マスタに登録」を押す。既にある品目なら定番商品と別名が更新される

### 在庫を数える

1. 引き出しを選ぶ（前回の在庫が表示される）
2. カメラで撮る。真上から、物を重ねずに。奥行きがあるなら手前と奥で分けて最大4枚
3. 「Claude に数えてもらう」を押す。20〜40秒で結果が出る
4. 品目名・数量・単位・残量目安を確認して直す。確信度「低」や「新規品目」は特に確認する
5. 「この内容でシートを更新」で確定。不足している品目があればその場で表示される

## 「いつも買う商品」の決め方

写真から読み取れる商品名は毎回ブレるので、注文に使う情報は認識結果ではなく品目マスタに固定で持たせます。

- **品目名** は種類名（例: `食器用洗剤 詰め替え`）。Claude はこの名前に寄せて返します
- **定番商品** に、いつも買う商品名（例: `キュキュット クリア除菌 詰替 770ml`）を書きます。買い物リストにはこちらが出ます
- **購入先** に URL や店名を書いておくと、買い物リストからそのまま注文に行けます
- 在庫シートの **見えた商品名** には、写真から読めたブランド・商品名が参考として残ります。定番商品を決めるときの材料にしてください

認識結果の画面で品目名を直すのは「その回の記録」を直す操作で、次回以降には効きません。次回も同じ間違いをさせたくない場合は、品目マスタの **別名** に誤認識された名前を足してください。

## 認識精度を上げるコツ

- 品目マスタに別名を足す（例: `トイペ`）。Claude はマスタの正規名に寄せて返します
- 詰め替え袋と本体ボトルは別品目として登録する
- 写真は明るい場所で、影が落ちないように
- 認識ミスは画面で直せば履歴に「認識結果」と「確定結果」の両方が残るので、後からプロンプト改善の材料になります

## 設定を変える

`src/Config.js` で変更できます。

| 項目 | 既定値 | 説明 |
|---|---|---|
| `MODEL` | `claude-opus-5` | 使うモデル |
| `EFFORT` | `medium` | 思考の深さ。GAS の外部通信は約60秒で切れるため `high` 以上は非推奨 |
| `MAX_PHOTOS` | 4 | 1回の撮影枚数の上限 |
| `SAVE_PHOTOS` | true | 写真をドライブの `在庫写真` フォルダに保存する |

## 制限と注意

- Claude は「写っている物」しか数えません。奥に隠れた物は数量が少なめに出ます。撮り方で補ってください
- 開封済み容器の残量は目安（未開封/多い/半分/少ない/空）です
- GAS の外部通信には時間制限があるため、まれにタイムアウトします。その場合は撮り直してください
- 写真は Claude API に送信されます。人物や個人情報が写り込まないようにしてください

## ファイル構成

```
scripts/
  bootstrap.mjs    初回: シート作成 + push + Web アプリ公開
  deploy.mjs       更新: push + 既存デプロイを新バージョンへ
.github/workflows/deploy.yml  main への push で自動反映（任意）
src/
  appsscript.json  マニフェスト（スコープ、Web アプリ設定）
  Config.js        設定とサンプルデータ
  Setup.js         メニューと初期設定
  Sheets.js        シートの読み書き、買い物リスト
  Claude.js        Claude API 呼び出し（画像認識、構造化出力）
  WebApp.js        doGet と画面から呼ぶ API
  Index.html       スマホ向け画面
```
